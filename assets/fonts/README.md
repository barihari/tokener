# Fonts

The open-source fonts are self-hosted under the SIL Open Font License 1.1. Recife Text is a licensed commercial font used for the Bankrate case-study theme; its licence is not redistributed here.

- Instrument Sans: Instrument, used for Bankrate body text and controls.
- Recife Text: Luzi Type, used for Bankrate display titles under an existing licence.
- Source Sans 3: Adobe Fonts, used as the open-source substitute for Capital One's proprietary Optimist typeface.
- Geist: Vercel, used for Sage body text.
- DM Sans: Google Fonts, used for Sage labels and controls.
- Libre Baskerville: Google Fonts, used for Sage display titles.

The matching open-source licence is stored beside each open-source font family.
