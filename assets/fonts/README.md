# Fonts

All fonts are self-hosted and licensed under the SIL Open Font License 1.1.

- Instrument Sans: Instrument, used for Bankrate buttons.
- Source Sans 3: Adobe Fonts, used as the open-source substitute for Bankrate body text and Capital One's proprietary Optimist typeface.
- Geist: Vercel, used for Sage body text.
- DM Sans: Google Fonts, used for Sage labels and controls.
- Libre Baskerville: Google Fonts, used for Sage display titles.

The matching license is stored beside each font family.
